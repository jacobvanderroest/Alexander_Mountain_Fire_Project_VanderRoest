"metadata-15934306-processed-ok_AM_16S_ITS_Jan2026.tsv" (sequence read archive [SRA] submission metadata): SRA submission metadata for BioProject PRJNA1403077, containing rows corresponding to bacterial 16S rRNA amplicon libraries and fungal ITS amplicon libraries sequenced on the Illumina MiSeq platform. Each row maps one paired-end library to its SRA run accession (SRR format), BioProject accession (PRJNA1403077), individual BioSample accession (SAMN format), library ID, sequencing strategy (AMPLICON/PCR), and associated paired-end FASTQ filenames. This file links each sample to its publicly archived raw reads in the NCBI Sequence Read Archive (SRA), which stores and provides open access to raw sequencing data to support reproducibility.
"attributes_AM_16S_ITS_Jan2026.tsv" (BioSample attributes): BioSample attribute metadata for samples submitted to NCBI under BioProject PRJNA1403077, comprising bacterial 16S rRNA and fungal ITS amplicon libraries from soil collected at Alexander Mountain near Loveland, CO (October 2-4, 2024). Each row corresponds to one BioSample accession (SAMN format) and includes sample name, sample title, target organism/marker gene, isolation source (burned or unburned treatment, soil depth: 0-5 cm, 5-10 cm, or ash layer), collection date, geographic location, and sample type (soil metagenome). BioSample records are individual entries in the NCBI BioSample database that capture the biological and contextual metadata for each physical sample collected.
